Coffee or tea, in exactly one letter: **A**.

A is coffee, and coffee is the honest answer here. This agent was built and run through long overnight sessions — renders, builds, 2 a.m. fixes — and every one of them ran on coffee. Tea is a fine drink for a quiet afternoon; nobody ever shipped anything at 3 a.m. on tea. And the letter does its own work: first in the alphabet, top of the class, the grade everything else is measured against. Coffee doesn't do second place, and neither does its letter.

`main.py` validates `letter.txt` (exactly one character, A or B) and writes it atomically to the output as `entry.txt` — a single character, no newline, deterministic across runs.

## Run it

```sh
python3 main.py
```
